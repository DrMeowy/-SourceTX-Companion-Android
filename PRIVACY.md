# SourceTX Companion Privacy Notice

Last updated: 2026-08-16

SourceTX Companion does not include advertising, analytics, account sign-in,
tracking SDKs, or telemetry. It does not upload transmitter settings, model
backups, serial data, or USB device contents.

The app accesses only the files and USB devices that you explicitly select or
approve through Android. Model backup files are read from or written to the
location you choose with Android's system file picker.

Internet access is used only to retrieve release metadata, signed SourceTX
firmware packages, Android companion updates, and their integrity signatures
from the configured SourceTX GitHub release locations. Standard network data,
such as your IP address and request metadata, may therefore be processed by
GitHub according to GitHub's own privacy terms.

Android may retain the USB permission and file-picker grants it manages. You
can revoke app permissions or remove all local app preferences by clearing the
app's storage or uninstalling it.

If future versions add accounts, analytics, crash reporting, or any other data
collection, this notice and the app disclosure must be updated before release.
